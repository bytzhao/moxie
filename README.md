# moxie
### A Claude-enabled Chinese literacy training platform.

--

**Overview:** Moxie is a platform built by Brian, designed for Brian. It is designed to approach reading, translating and typing Chinese text in a gameified way. Since usage is inherently selfish, the primary goal is to improve *Brian's* literacy and fluency such that he is prepared to take CHN 303W at Emory University in one year's time. 

## Stack
Vanilla frontend - HTML, CSS, JS.
Backend - FastAPI (Python).
Vocab DB (TBD) - SQLite or something similar. Perhaps jump straight to PostgresSQL DB. Probably not Supabase (too easy and abstracted maybe).
